# The Proper Barbershop website

A five-page static website: Home, Services, About, Gallery, Contact. All seven supplied image files are included locally in `assets/`, including the official logo. The logo has been prepared as a transparent PNG for display.

## Deploy to Vercel

1. Extract the ZIP, then push the contents to a GitHub repository.
2. Import the repository into Vercel. Use **Other** as the framework preset, leave the build command empty, and set the output directory to `.` if prompted.
3. Deploy. The website uses regular HTML pages and requires no backend.

Book buttons open the business's existing Square booking page. Contact information, services, and hours are based on the previous website as checked on September 25, 2026. Confirm live details with the business before going live. Fonts and the embedded map load from external services; all site photographs and the logo are bundled in the ZIP.
