# The Proper Barbershop website

Five-page static site: Home, Services, About, Gallery, Contact. The official supplied logo and all supplied photos are bundled locally in `assets/`. The original warm ivory, charcoal, and bronze color theme is retained. New shop and team photos are featured throughout the pages, with varied photos in each major section.

## Deploy to Vercel

Extract this ZIP and push its contents to GitHub. Import the repository into Vercel, select **Other** if asked for a framework, leave the build command empty, and set the output directory to `.` if prompted.

The booking buttons open the shop's existing Square booking page. The embedded map and web fonts need an internet connection. Business hours and service details came from the previous business website and should be confirmed before launch.
